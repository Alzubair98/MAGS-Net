# Scratch classification baselines

Open [`02_Baseline_Classification_NestedCV.ipynb`](../02_Baseline_Classification_NestedCV.ipynb)
with the Conda `dl` kernel. All explanations and code are in English. Training and new
outer-test inference are disabled by default.

The five new classifiers are **ResNet-50, DenseNet-121, EfficientNet-B0,
MobileNetV3-Large, and RegNet-Y-400MF**. Every TorchVision constructor uses `weights=None`
and three output classes; its first convolution is freshly initialized for one input channel.
No ImageNet weights are downloaded or loaded. MAGS-Net's completed outer-test predictions
are imported as the sixth comparison row; MAGS-Net is not trained by this notebook.

## Data and saved folds

The notebook reads `brainDataset_cropped/metadata_clean.csv` and the same processed MRI PNGs
used by MAGS-Net. It uses grayscale **1 x 224 x 224** input, OpenCV linear resizing, division
by 255, independent horizontal/vertical flips with probability 0.5, and uniform rotation
between -10 and +10 degrees. Training alone uses augmentation. Labels are:

| Label | Class |
| --- | --- |
| 0 | Meningioma |
| 1 | Glioma |
| 2 | Pituitary |

Classifier datasets return images, labels, and identifiers only. Masks are read once during
the provenance audit to verify that the processed dataset matches the saved MAGS-Net data
fingerprint; masks do not enter a classifier, augmentation, loss, or evaluation.

`MAGS_STUDY_DIR` points to the completed local study
`results/magsnet_nested_cv/20260916T210025Z_bc27ff71`. The notebook reads its experiment
record, saved patient assignments, and five outer-test prediction files. The corresponding
preparation directory is `results/magsnet_nested_cv/preparation/04ddbd02826f` and supplies
`outer_patients.csv`, `inner_patients.csv`, and `sample_index.csv`. Fold contents must match
the experiment record exactly. No folds are generated by the baseline notebook.

To use the notebook elsewhere, retain the processed dataset, the referenced MAGS-Net study
(including its refit checkpoints and evaluation metadata), and the matching preparation
directory. Update `MAGS_STUDY_DIR` for another completed reference study. The notebook checks
file hashes, class mapping, complete coverage, and patient separation before fitting.

## Training protocol

| Setting | Value |
| --- | --- |
| Seed | 42 |
| Patient partitions | Saved outer 5-fold / inner 5-fold |
| Batch size | 32 |
| Optimizer | Adam |
| Initial learning rate | 0.001 |
| Weight decay | 1e-4 |
| Maximum inner epochs | 50 |
| Early-stopping patience | 10 |
| Scheduler | StepLR, step 10, gamma 0.5 |
| Loss / selection criterion | Minimum validation Cross-Entropy |

The MAGS-Net mixed-precision and gradient-clipping policy is retained. Its sampler policy
is also retained: a final singleton training batch is merged into the previous batch,
producing 33 images in that final batch when needed, without dropping any image.

For **each architecture and outer fold**, five fresh inner models select their own best
epochs. The median of those five epochs sets the duration of a new model trained on the
entire outer-development set. MAGS-Net's selected epochs are never used to train a baseline.
The outer model has no validation or test loader during fitting; its final checkpoint is
used for evaluation. This produces **150 new fits**: five architectures times
(25 inner fits + five outer refits).

## Run later

1. Run all cells with the default switches to audit the dataset/folds, perform forward-only
   model checks, and export the saved MAGS-Net reference. This performs no training.
2. When ready to train, set `RUN_TRAINING = True`, `RUN_OUTER_TEST = False`, and
   `BASELINE_STUDY_DIR = None`, then run from the top. Save the printed study directory.
3. After all fits finish, set `BASELINE_STUDY_DIR` to that directory, set
   `RUN_TRAINING = False` and `RUN_OUTER_TEST = True`, then run from the top to evaluate.
4. For subsequent analysis, retain `BASELINE_STUDY_DIR` and disable both switches. Saved
   predictions are reused without training or repeated test inference.

An explicit existing study path reuses verified completed fits. A partial fit stops with
its path identified; automatic resumption from the middle of an epoch is not implemented.
To restart only that partial fit, retain the other completed fits and explicitly move the
incomplete fit directory aside before rerunning with the same study path. Leaving
`BASELINE_STUDY_DIR = None` starts a separate study on every training execution.

## Saved outputs

Outputs are separate from MAGS-Net under `results/baseline_classification_nested_cv/`.
Each inner fit saves `history.csv`, `summary.json`, and best/last model checkpoints.
Each outer fold saves its five inner best epochs, selected median duration, refit history
and final checkpoint, and test predictions with evaluation provenance.

The study's `analysis/` directory contains per-model slice OOF files with:

```text
model, outer_fold, sample_id, patient_id, true_label, predicted_label,
prob_meningioma, prob_glioma, prob_pituitary, seed
```

For the supplied dataset, each completed model must cover **3,064 slices, 233 unique patients,
and zero duplicate samples**. `oof_coverage.csv` reports measured coverage; pending models
are explicitly marked `not_evaluated`, with no invented performance values.

Additional outputs include patient predictions formed by averaging slice probabilities,
slice/patient classification metrics, per-class precision/recall/F1, architecture-specific
epoch selections, and combined predictions. Confusion-matrix and ROC comparison figures
are exported as PNG/PDF after all six models have complete OOF results. Before baseline
training, the default run exports only the actual MAGS-Net reference under
`preparation/<protocol hash>/reference/`.

MAGS-Net used **classification + 0.5 segmentation + 0.2 auxiliary localization loss**.
The five baselines use **Cross-Entropy only**. This difference in supervision is explicitly
labeled in the comparison table; the comparison evaluates the complete training systems.

### Model complexity

Section **18.1** exports `analysis/model_complexity.csv` with Model, Parameters, MACs, and
FP32 model size (MiB) for all six models. It profiles the five one-channel baselines on one
synthetic 224 x 224 image and imports MAGS-Net's existing `analysis/complexity.csv`, which
uses the same Conv2d/Linear counting convention for the full multitask model. Keep that
MAGS-Net report with the reference study. Running these cells does not train or evaluate
on the dataset.

MACs exclude bias additions, normalization, activations, pooling, interpolation, and
elementwise operations. They are not total FLOPs. FP32 parameter size is parameter count
times four bytes, divided by 2**20; it excludes buffers and checkpoint overhead. The
accompanying `model_complexity_metadata.json` records these definitions, input shape,
and the source MAGS-Net report hash.

The percent-format Python source and corresponding build script are in this directory.
